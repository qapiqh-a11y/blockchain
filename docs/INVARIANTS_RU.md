# Security invariants

1. **Только OPERATOR_ROLE изменяет состояние билета.** Любой адрес без этой роли не должен успешно выполнить registerTicket, validateTicket или revokeTicket.
2. **Revoked — терминальное состояние.** После перехода билета в Revoked ни одна допустимая последовательность вызовов не должна вернуть его в Created или Validated.
3. **ticketId уникален.** После первой успешной регистрации того же ticketId повторная регистрация всегда должна завершаться revert.
4. **Целостность off-chain записи.** dataHash, сохранённый при регистрации, не изменяется функциями смены validationStatus.

Первые три полностью соответствуют требованию минимум трёх инвариантов. В тестах два свойства дополнительно проверяются fuzz-тестированием.
